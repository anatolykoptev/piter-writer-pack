# Changelog

All notable changes to this pack are recorded here, in the
[Keep a Changelog](https://keepachangelog.com/en/1.0.0/) format. No versions are tagged, so
entries are grouped by date.

## [Unreleased]

### Added

  `docs/INDEX.md`, issue and pull-request templates.

## 2026-10-11

### Added

- Initial pack: the go-wp writer skills (`create-article`, `create-events`, `update-article`,
  `update-facts`, `update-single`, `fix-article`, `news-pipeline`, `maintenance`),
  `podborka-editorial` and the `piter-writer` invariants and authority boundary, generated by
  `sync.sh`.
- `README.md` as an agent-facing self-serve setup guide for a link-only handoff.

### Changed

- The README no longer has a private-repository authentication section; the repository is public.
- The writer username travels with the token, so the pack is identity-agnostic.
- Token delivery is out of band: a `.env` file, a file in the home directory, or the clipboard,
  never the chat; `.env` is git-ignored. The README includes a ready instruction the agent hands to
  its human when no token is found.
